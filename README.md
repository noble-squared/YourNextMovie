# Your Next Movie

Final project for CSCI3010: Intensive Programming Workshop.

Look up movies you've watched and get recommendations for what to watch next. Make an account, and get more personalized results; plus, it's guaranteed you'll never be recommended something you've already watched.

Connects to the TMDB API for movies using Hono. The frontend, Vite, connects to Supabase for authentication and profiles, with a dynamic UI created with React and Typescript.
